# Remote Pilot Academy landing page

The landing page for Remote Pilot Academy, a game by andAgainSoftware. It is a single static page with no build step: `index.html` plus the pictures and video in `media/`. Every path is relative.

Live: https://mathew-harvey.github.io/RemotePilotAcademy-landing/

GitHub Pages publishes the `gh-pages` branch. After a change on `main`, push it to both:

```
git push origin main
git push origin main:gh-pages
```

Copy on this page avoids em dashes and en dashes.
